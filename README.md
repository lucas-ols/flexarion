# 🚀 FLEXARION

> *Dans un futur lointain, l'humanité a franchi les frontières de la galaxie...*

**Flexarion** est un site web de science-fiction développé dans le cadre d'un projet de développement web. Il plonge le visiteur dans un univers futuriste fait de vaisseaux, de planètes inconnues et de technologies avancées.

---


## 🌌 Présentation

Flexarion est un site web immersif au thème science-fiction. Le projet a pour objectifs de :

- Proposer une expérience visuelle moderne et futuriste (néons, animations, ambiance spatiale)
- Mettre en pratique les compétences acquises en développement web
- Travailler en équipe avec une gestion de projet collaborative

---

## ✨ Fonctionnalités

- 🛸 Page d'accueil immersive avec animations
- 🪐 Présentation de l'univers Flexarion (lore, planètes, factions)
- 🧑‍🚀 Section personnages / équipage
- 🖼️ Galerie d'images et d'illustrations
- 📱 Design responsive (ordinateur, tablette, mobile)
- 📬 Page de contact
